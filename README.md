# Mariposas Blancas

Átomos Dispersos es nuestro proyecto musical independiente; _Mariposas Blancas_ es nuestro primer EP, completamente producido y publicado por nosotros mismos. Durante su desarrollo utilizamos este repositorio como copia de seguridad que sirviera como respaldo para toda la información del álbum, incluyendo las grabaciones crudas, los archivos de Reaper donde se mezcló y masterizó, las letras y el arte visual. Ahora que el álbum se publicó (el 29 de enero de 2026), queremos dejar este repositorio público como una muestra del trabajo que hicimos y cómo lo hicimos.
